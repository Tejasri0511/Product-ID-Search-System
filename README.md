
# Product ID Search System

## Project Title
Comparative Performance Analysis of Product Searching Using BST, AVL Tree and Hashing with Linear Probing.

## Project Description
This project compares three data structures used for searching product records: Binary Search Tree (BST), AVL Tree and Hashing with Linear Probing.

The system stores product details and allows users to insert, search and display product records. It also compares the searching performance of the three data structures.

## Objectives
- To implement BST, AVL Tree and Hashing.
- To perform product insertion and searching.
- To handle collisions using Linear Probing.
- To compare search comparisons, tree height and hash collisions.
- To identify the suitable data structure for product searching.

## Technologies Used
- Programming Language: Java
- IDE: Visual Studio Code
- Version Control: Git and GitHub

## Data Structures Used

### 1. Binary Search Tree (BST)
Stores product records based on Product ID.

### 2. AVL Tree
A self-balancing binary search tree that maintains balanced height.

### 3. Hashing with Linear Probing
Uses a hash function to store product records and linear probing to handle collisions.

## Features
- Insert product details
- Search products by Product ID
- Display BST records using inorder traversal
- Display AVL Tree records
- Display hash table contents
- Compare performance of all three data structures

## Dataset
The project uses 30 unique product records for performance comparison.

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   javac Main.java

5. Run the program:

   java Main

## Expected Output
The program displays a menu for product insertion, searching, displaying data structures and comparing their performance.

## Conclusion
This project demonstrates how BST, AVL Tree and Hashing with Linear Probing can be used for product searching. Their performance is compared using experimental observations to identify the most suitable data structure.
